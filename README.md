# Docs in Motion

This repository contains a small public Quarto website with three documentation articles.

## Project structure

- `_quarto.yml` — Quarto site configuration
- `index.qmd` — home page
- `docs/articles/article-1.qmd` — article on planning documentation
- `docs/articles/article-2.qmd` — article on writing clear technical content
- `docs/articles/article-3.qmd` — article on publishing with Quarto
- `styles.css` — site styling

## Local preview

```bash
quarto render
quarto preview
```

## Publish to GitHub Pages

This project is designed to be published as a public site using GitHub Pages or any static hosting platform.
